This Mod adds a Granturismo 3 Hud to the Game.

Key features:
- MPH and KMH Support
- Changeable accent color with 8 different presets
- Both Chase and Bumper Camera Hud are included
- Redline adjust to your car's redline in realtime
- Milage and Trip counter. the Trip counter can be reset at any time.
- Input Trackers that display your inputs from the original game's replay system
- Working Boost Gauge


Install:

1. Download the Zip from the Releases Tab
2. Drag the contents of the Zip into CarX Drift Racing Online\kino\mods
3. Launch the Game and Done
